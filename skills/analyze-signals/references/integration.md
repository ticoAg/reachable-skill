# 工具连接与工程实践

## 两个工具之间的适配

先检查生产方输出和消费方输入。优先直接传原生对象或保存原格式，再用短的、任务专属的 adapter 处理差异。不要建立跨模态统一结果对象。

| 连接 | 常见差异 | 处理与验证 |
|---|---|---|
| SoundFile → librosa | `(frames, channels)` 与 channel-first 布局 | 显式转置；用已知声道样本检查，不凭二维 shape 猜测 |
| OpenCV → 视觉模型 | BGR/RGB、像素范围、尺寸 | 显式转换颜色；记录 resize/crop 到原图的坐标映射 |
| pandas → SciPy DSP | 不规则时间、NaN、单位 | 先检查时间间隔；需要时重采样，记录插值段；再传数值数组与真实 fs |
| MNE → 数值模型 | channel×time、SI 单位、通道顺序 | 按模型要求选择通道和布局；避免重复 µV/V 转换 |
| SigMF → GNU Radio | 端序、complex dtype、捕获参数 | 读取声明的格式；复数样本转为目标 block 需要的格式，保留中心频率等外部信息 |
| Open3D → 渲染器 | 单位、轴向、法线、材质 | 显式变换坐标；用已知尺度和方向验证 |

以上为工程建议，不是已在所有版本上运行的互操作测试。

## 环境和规模

- 按领域隔离依赖，固定可复现环境；避免全局安装所有模型框架和工具。
- 用参数数组调用子进程，检查 return code 与 stderr。Shell 管道示例只用于可控文件名。
- 小片段先验证 shape、单位和结果；大文件采用 memmap、分块 reader、流式解码。滤波器、STFT 和事件跨块需要 overlap 或状态，不能把各块当完全独立信号。
- 跨设备时间同步区分 offset、drift、jitter。保留各来源时钟与同步变换；没有共同事件或时钟时不要声称精确对齐。
- 保留未处理输入；以工具原生配置、命令日志或实验笔记记录版本、随机种子和变换。它们不是分析结果的强制外壳。

## 模型与生成工具

先区分数值特征、识别标签和自然语言解释。把有损摘要送入模型后，不再把模型回答当作原始测量。实际模型需检查输入窗口、采样率、token/patch 限制、权重来源、硬件和许可。

生成端可以消费音符、参数曲线、mask、几何、文本 prompt、embedding 或原始信号。检查当前生成器自己的接口，不要求其接受统一 IR。对随机输出记录 seed（如支持），并以目标领域的格式、频谱、统计或几何检查评价结果。

未知模态接入时，在单独的 skill/reference 记录原始 reader、分析方法、生成选项和失败条件；只约束具体工具调用所必需的输入，不改变全仓库数据表示。
